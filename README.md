Personal academic website, served by GitHub Pages (Jekyll) at https://rafael060.github.io.

Edit it without touching code at https://app.pagescms.org (sign in with GitHub, open this repo).

- `_data/profile.yml` — name, position, bio, email, CV, links ("About me" in Pages CMS)
- `_papers/*.md` — one file per paper ("Papers" in Pages CMS)
- `files/` — uploaded PDFs
- `index.html` — page template and styling; `_includes/paper.html` — one paper entry
- `.pages.yml` — Pages CMS form definitions
